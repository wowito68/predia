# Checklist telefono evaluacion

- [ ] Instalar Expo Go o APK.
- [ ] Configurar API URL alcanzable desde el telefono.
- [ ] Probar login medico.
- [ ] Probar login paciente.
- [ ] Crear/editar/reagendar/cancelar una cita demo.
- [ ] Registrar automonitoreo.
- [ ] Generar PDF/impresion de receta o resumen.
- [ ] Verificar bateria mayor a 70%.
- [ ] Llevar cargador.
- [ ] Desactivar actualizaciones automaticas durante exposicion.
- [ ] Entregar telefono desbloqueado a evaluadores.
